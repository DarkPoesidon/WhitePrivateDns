# به‌روزرسانی نصب موجود در لینوکس

برای سروری که WhitePrivateDns از قبل روی آن نصب است، از `scripts/update.sh` استفاده کنید. `scripts/install.sh` نصاب **نصب تازه** است و پس از تأیید `FRESH` داده‌های نصب قبلی را جایگزین می‌کند.

دستورهای زیر را با کاربر `root` روی سرور اجرا کنید؛ به Go یا نسخهٔ کلون‌شدهٔ پروژه نیاز ندارند و از هر پوشه‌ای کار می‌کنند:

```bash
TAG='v2.2.0-beta.5'
curl -fsSLo /tmp/whiteprivatedns-update.sh \
  "https://raw.githubusercontent.com/DarkPoesidon/WhitePrivateDns/${TAG}/scripts/update.sh"
env WHITEPRIVATEDNS_REF="$TAG" \
  WHITEPRIVATEDNS_REPOSITORY='DarkPoesidon/WhitePrivateDns' \
  bash /tmp/whiteprivatedns-update.sh
```

اسکریپت باینری Linux متناسب با معماری سرور و فایل نسخه را از همان تگ می‌گیرد، SHA-256 باینری را با فهرست Release بررسی می‌کند و پیش از جایگزینی، از پوشهٔ نصب آرشیو قابل خواندن می‌سازد. `config.json`، `data.db`، `master.key` و گواهی‌ها حفظ می‌شوند. اگر سرویس تازه روشن نشود، آرشیو قبلی و وضعیت روشن یا خاموش بودن سرویس بازیابی می‌شود. هنگام به‌روزرسانیِ سرویس روشن، وقفهٔ کوتاهی در DNS رخ می‌دهد.

پس از اجرا، مسیر و SHA-256 آرشیو در خروجی چاپ می‌شود. آن را تا زمانی که پنل و پاسخ DNS را بررسی کرده‌اید، در جای امن نگه دارید؛ آرشیو شامل تنظیمات و کلید خصوصی است.

```bash
systemctl status whiteprivatedns --no-pager
/opt/whiteprivatedns/whiteprivatedns -version
```

راهنمای کامل‌تر و روش بازگردانی دستی در [UPDATE.md](UPDATE.md) آمده است. این اسکریپت مخصوص نصب‌های Linux با `systemd` روی `amd64` یا `arm64` است.

## به‌روزرسانی از داخل داشبورد

دیمن هنگام راه‌اندازی و هر شش ساعت، نسخه‌های GitHub Releases را بررسی می‌کند. وقتی نسخهٔ جدیدتری باشد، بنری بالای داشبورد با تغییر نسخه و پیوند یادداشت‌های انتشار نشان داده می‌شود. نصب پایدار (stable) فقط نسخهٔ پایدار پیشنهاد می‌گیرد؛ نصب بتا نسخه‌های بتا را هم می‌بیند.

با زدن **Update now** و وارد کردن رمز عبور فعلی (و کد 2FA، اگر فعال است):

1. اسکریپت `whiteprivatedns-update.sh` همان نسخه دریافت می‌شود و فقط اگر SHA-256 آن با `checksums.txt` همان Release بخواند پذیرفته می‌شود؛
2. اسکریپت در یک واحد جداگانهٔ systemd به نام `whiteprivatedns-update` اجرا می‌شود تا با راه‌اندازی مجدد سرویس از بین نرود؛
3. اسکریپت از `/opt/whiteprivatedns` پشتیبان می‌گیرد، باینری را جایگزین می‌کند، سرویس را دوباره راه می‌اندازد و اگر نسخهٔ جدید سالم بالا نیاید خودکار به نسخهٔ قبلی برمی‌گردد.

پس از بازگشت سرویس، پنل خودش به صفحهٔ ورود بارگذاری می‌شود. اگر مشکلی پیش آمد، گزارش را با `journalctl -u whiteprivatedns-update` ببینید.

به‌روزرسانی خودکار فقط برای نصب استاندارد کار می‌کند: لینوکس، systemd، اجرا با root و باینری در `/opt/whiteprivatedns/whiteprivatedns`. در Docker یا چیدمان‌های دیگر اعلان نشان داده می‌شود ولی دکمه دلیل عدم امکان را توضیح می‌دهد.

متغیرهای محیطی سرویس: `WHITEPRIVATEDNS_UPDATE_CHECK=0` بررسی GitHub و بنر را خاموش می‌کند؛ `WHITEPRIVATEDNS_REPOSITORY=owner/repo` یک fork را به‌جای مخزن پیش‌فرض بررسی می‌کند. این بررسی فقط یک درخواست به `api.github.com` می‌فرستد و هیچ اطلاعاتی از نصب شما ارسال نمی‌کند.
