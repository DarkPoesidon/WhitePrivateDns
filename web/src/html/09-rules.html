Network paths

Use these controls when the current address is unreachable from a subscriber network. Test each path before sharing it with clients.

راهنمای فارسی تمام بخش‌های پنل و Network paths

Active relay IPv4

The address returned for proxied domains. Changes apply to new DNS answers immediately.

Use only an IPv4 address assigned to this server. Existing connections keep their current route; clients may cache older DNS answers for up to 60 seconds.

Public DoH URL

Optional HTTPS address behind a CDN or tunnel, shown in connection guides.

This only changes the address shown to clients. Set up the CDN or tunnel first, keep local DoH running, bypass caching and browser challenges for /dns-query, and test from a subscriber network. Clear the field to restore the direct URL.

Automatic Cloudflare or WARP setup and multi-server failover are not available in this release.

Subscription Portal

A port other than the panel's opens a dedicated public listener for the subscriber pages. Open it in the host firewall too — on Ubuntu that is ufw allow <port>/tcp — or the links in this card will time out from outside even though the daemon is serving them.
